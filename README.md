# NewsNow - A Premium Android News Experience

NewsNow is a personalized news application designed for Indian users who want to stay updated in their native language. It provides a seamless and clutter-free reading experience with a focus on speed and design.

### Why NewsNow?
Most news apps are cluttered with ads and generic content. I built NewsNow to provide a clean, Material 3 based interface that supports multiple regional languages, making it accessible to everyone.

---

### Key Features

*   **Regional Language Support**: Choose from **English, Hindi, Gujarati, Marathi, or Kannada**. The entire UI adapts to your selection.
*   **Adaptive Themes**: Fully optimized for Dark and Light modes.
*   **Latest Headlines**: Real-time news fetching using NewsAPI.
*   **Auto-Refresh**: Stay updated with automatic feed refreshing every 15 seconds.
*   **Smart Categorization**: Easily browse through Technology, Business, Sports, and more.
*   **News Tech Support**: Integrated help center and feedback form for a complete user experience.

### 🛠 Technical Specifications

*   **Language**: Java
*   **UI Framework**: Material Design 3 (M3)
*   **Library - Networking**: Retrofit 2
*   **Library - Image Loading**: Glide
*   **Local Persistence**: SharedPreferences for user preferences and locale.
*   **External API**: NewsAPI.org

### 🚀 Setup Instructions

1.  Clone this repo: `git clone https://github.com/your-username/NewsNow.git`
2.  Open the project in Android Studio.
3.  Add your API Key in `com.example.newsnow.utils.Constants.java`.
4.  Run the app on your emulator or device.
